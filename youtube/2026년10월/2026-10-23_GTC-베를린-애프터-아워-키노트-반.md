## AWS Developers

### REST API란 무엇인가? (5분 만에 만들기)
https://www.youtube.com/watch?v=-0wzIlNQN1I

- 아빠 농담 API를 예제로 REST API의 기본 개념을 설명한다.
- API를 계약으로 정의하고 요청의 4가지 구성 요소(메서드, 경로, 헤더, 바디)와 응답의 3가지 구성 요소(상태 코드, 헤더, 바디)를 다룬다.
- CRUD 연산이 HTTP 동사(GET, POST, PUT, DELETE)에 어떻게 매핑되는지와 주요 상태 코드(200, 404, 400, 500)를 설명한다.
- REST의 무상태 특성이 AWS Lambda와 잘 맞아떨어지는 이유를 설명한다.
- API Gateway와 Lambda로 실제 REST API를 구축하는 과정을 시연하고 HTTP API와 REST API의 선택 기준을 제시한다.
