### Argo Workflows와 SageMaker로 추천 ML 파이프라인 구축기
원문: https://helloworld.kurly.com/blog/recommend-ml-pipeline/

- 컬리 AI검색추천개발의 백엔드 엔지니어 유성규가 추천 모델의 학습부터 서비스 반영까지 자동으로 이어지는 파이프라인 구축 과정을 소개했다.

- 세대가 다른 벡터를 섞으면 추천 품질이 떨어지므로 산출물별 트랜잭션 대신 세대(Generation)를 구분하고, 활성 키 값만 바꿔 전체를 전환하는 구조를 택했다.
- 요구사항은 학습부터 색인까지의 매일 자동 연결, 모든 산출물의 동시 세대 전환, 파이프라인 실패 시 서비스 무영향, 추론 불가 모델의 전환 전 필터링이었다.
- 특정 언어에 묶이지 않는 범용 워크플로우 엔진으로 EKS 표준 아키텍처에 맞는 Argo Workflows를, 하루 4~5시간 GPU 학습을 위해 GPU 노드를 24시간 띄우지 않도록 ML 런타임은 SageMaker를 선택했다.

### 개인화 비디오 기술: 7년간의 알고리즘演进
원문: https://mp.weixin.qq.com/s?__biz=MzI1MzYzMjE0MQ==&mid=2247523974&idx=1&sn=71549486fa67ac09532748b26bc01fed

- 더우인은 기본 영상 소비 외에 커머스, 라이브, 이커머스, 지역 생활 서비스, 숏드라마, 게임, 검색 등 수십 개 사업을 함께 운영하며 유창성·화질·안정성·실패율·비용의 종합 최적을 추구한다.
- VLP(Video Lifecycle Prediction)는 매일 수천만~수억 개 업로드 영상의 미래 가치(vv, 재생 시간)를 예측해 트랜스코딩 우선순위, CDN 캐시 전략, 배포 가중치, 전처리와 콘텐츠 이해 추론 예산을 결정한다.
- VLP v1(2021)은 추천식 리콜·랭킹 파이프라인과 수십 개 작가·영상 특징으로 가치 예측을 지도학습으로 구현하고 0~1 열기도 점수로 정규화해 트랜스코딩 정렬에 사용했다.
- VLP v3(2023)는 초대규모 희소 DNN과 일 단위 갱신, LHUC·wide&deep, GradNorm 기반 멀티태스크를 도입했고, VLP v8(2026)은 TokenMixer 기반 구조로 dense 파라미터를 1B까지 늘려 v7 대비 Reg-AUC +1.36%, MFU +167%를 기록했다.

### OpenAI의 Git 확장: Pando 백엔드 구축
원문: https://openai.com/index/scaling-git-at-openai

- OpenAI는 엔지니어링 작업을 중단하거나 팀의 Git 사용 방식을 바꾸지 않고 Git 저장소용 새 백엔드 Pando를 구축했으며, 현재 모노레포의 모든 개발이 Pando로 운영된다.
- Pando는 여러 브랜치에 대한 동시 푸시에 최적화된 수평 확장 쓰기와, 클라이언트가 가용 네트워크 대역폭을 최대한 채울 수 있는 읽기 처리량이라는 두 가지 목표를 위해 설계됐다.
- Git 프로토콜 및 클라이언트와의 호환성을 유지해 엔지니어와 에이전트 모두 기존 워크플로에 Pando를 그대로 도입할 수 있었다.
- 프로덕션에서 Pando는 푸시 지연 시간 중앙값을 약 5배 줄였고, 하루에 거의 1페타바이트의 Git 데이터를 제공한다.
- Codex로 인해 병렬 작업이 늘면서 브랜치·푸시·병합·페치·클론 수요가 복합적으로 증가했고, 지난해 말 무렵에는 느린 페치와 푸시, 병합 실패로 안정성이 때때로 90% 아래로 떨어졌다.
