## ZOZO TECH BLOG

### AI로 Classic ASP 에뮬레이터를 만들어 리플레이스 진행
원문: https://techblog.zozo.com/entry/classic-asp-emulator-with-ai

- ZOZO의 핵심 시스템은 Windows Server IIS에서 Classic ASP와 VBScript로 구축되어 왔으며, Microsoft의 VBScript 폐지 발표로 유지보수가 어려워져 리플레이스가 급무가 됐다.
- 시스템은 Classic ASP 위에 서드파티 클로즈드 프레임워크를 올린 구성이라 E2E 테스트는페이지 간 의존성·대량 데이터로 어려우며, VBScript는 모듈 시스템이 없어 유닛 테스트도 글로벌 변수 의존으로 난해하다.
- Classic ASP는 Windows에서만 실행돼 개발 환경이 제한적이므로 에뮬레이션이 필요했고, 기존 OSS의 정확도가 부족해 VBScript를 JavaScript로 변환하는 컴파일러를 자작했다.
- AI가 VBScript 코드를 대량 생성하여 Windows 가상 환경에서 실제 출력 기록을 남기고, 그 출력을 정답으로 삼아 컴파일러를 구현했으며 인간은 macOS 가상 환경 실행만 담당해 약 1주 만에 완료했다.
- 변환된 JavaScript는 1:1 대응이 아니고 가독성이 낮으며, On Error Resume Next와 참조 전달 인자 등 VBScript 특유의 동작 재현이 불가피하다.

### Retell이 OpenAI 모델로 월 1억 건 통화를 처리함
원문: https://openai.com/index/retell-ai

- Retell AI는 4,000개 이상 기업이 사용하는 컨택트센터 음성 AI 플랫폼이고 월 통화량이 2026년 초 3,000만 건에서 9월 1억 건 이상으로 증가했다.
- Retell의 통화 중 80% 이상이 OpenAI 모델이 응답을 생성하며 고객 해결율은 80% 이상이고 OpenAI 모델 소비 토큰은 1조 개를 넘었다.
- Retell 엔지니어는 익숙하지 않은 코드 조사부터 기능 개발, 디버깅까지 Codex를 사용하며 GPT-6 Astra로 프론트엔드 인터페이스를 테스트한다.
- Retell은 실제 운영 다중 대화로 구성된 vCX 벤치마크를 만들어 모델들을 비교하며, 2026년 10월 13일 기준 GPT-6 Astra가 지시 따라가기 평가에서 89.7%로 1위를 차지했다.
- GPT-5.5는 추론 활성화 시 환각률 88.0%, 도구 호출 정확성 88.3%에서 다른 모델보다 높았고 Retell은 새 OpenAI 모델 출시 즉시 제공하며 벤치마크를 재실행한다.
