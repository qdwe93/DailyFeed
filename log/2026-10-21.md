### 장애 및 처리 기록

1. RSS 원문 접근: GeekNews RSS는 웹 도구에서 Atom 콘텐츠 유형을 지원하지 않아 직접 열기 실패. GeekNews의 2026-10-20 날짜별 지난 소식 페이지와 개별 글로 대체 조회하여 22건 저장.
2. 외부 네트워크: 로컬 실행 환경에서 DNS 조회 실패로 RSS 직접 요청 불가. 웹 검색과 공식 게시 목록으로 확인 가능한 범위만 조사.
3. YouTube: 채널 동영상 페이지에서 업로드 날짜와 자막을 확인할 수 없어 신규 영상 확정 불가. 추정 항목을 넣지 않고 제한 사항을 파일에 표시.
4. Tech Feeds GitHub 저장: 파일 생성 요청이 OpenAI 안전 검사에서 차단됨. 동일 경로로 본문을 줄여 두 번 재시도했으나 같은 오류가 발생. 구체적인 차단 원인은 제공되지 않음. GitHub API 오류라는 증거는 없음. Tech 파일 미생성 상태.
5. 일부 기술 블로그는 검색 결과가 없거나 robots.txt 제한으로 전체 신규 여부를 확정할 수 없음. 신규 없음으로 단정하지 않음.
